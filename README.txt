# RM Service Telegram Bot

Готовый бот для приема заявок на скупку и ремонт телефонов.

## Безопасность
Токен бота НЕ хранится в этом архиве. Старый токен, который был опубликован в чате, нужно отозвать через @BotFather и создать новый.

## Что умеет
- Главное меню с кнопками
- Скупка: производитель → модель → состояние → комплект → фото → телефон
- Ремонт: проблема → модель → фото → телефон
- Уведомляет администратора о новой заявке
- Пересылает фотографии администратору
- Разделы «Купить», «Адрес и контакты», «Связаться с менеджером»

ADMIN_ID уже установлен как 487674664.

## Запуск
1. Установить Python 3.11+.
2. Выполнить:
   pip install -r requirements.txt
3. Задать новый токен:
   BOT_TOKEN="НОВЫЙ_ТОКЕН" python bot.py

Windows PowerShell:
   $env:BOT_TOKEN="НОВЫЙ_ТОКЕН"
   python bot.py

Бот должен быть запущен постоянно на компьютере или сервере, чтобы принимать заявки.
