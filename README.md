# RM Service Telegram Bot

Бот принимает заявки на скупку и ремонт телефонов и пересылает их администратору.

Переменные окружения (Railway -> Variables):
- BOT_TOKEN — токен от @BotFather (в код не вставлять)
- ADMIN_ID — числовой Telegram ID администратора (узнать у @userinfobot)
- MANAGER_USERNAME — ник менеджера без @ (необязательно; по умолчанию кнопки ведут в канал)

Запуск: python bot.py
